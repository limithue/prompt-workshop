# 提示词工坊 PromptWorkshop

结构化提示词优化与效果对比的网页演示工具。课程作业项目，用于直观展示大模型提示词工程的价值。

## 功能

1. **需求输入**：一句大白话描述需求，支持 5 种任务场景（通用 / 编程 / 文案 / 数据分析 / 学习辅导）。
2. **六要素结构化**：自动生成 角色、任务、背景、输出格式、参考示例、约束条件，逐项可编辑并实时同步到完整提示词。
3. **效果对比**：同一需求的「原始提示词」与「优化后提示词」并排回答，差异一目了然。
4. **一键复制**：生成的完整提示词可直接复制使用。

## 两种运行模式

| 模式 | 说明 |
| --- | --- |
| 演示模式（默认） | 内置规则引擎与场景回答模板，完全离线，无需 API Key |
| 真实 API 模式 | 兼容 OpenAI Chat Completions 接口，预设 DeepSeek / 通义 / Kimi / OpenAI |

真实 API 模式的密钥仅保存在浏览器 `localStorage`，不会写入代码或提交到仓库。

## 使用

双击 `index.html` 用浏览器打开即可，无需安装任何环境或启动服务器。

## 对应知识点

- 六要素提示词结构
- 角色设定（Role Prompting）
- 少样本示例（Few-shot）
- 输出格式约束
- 评估与迭代

## 技术栈

原生 HTML + CSS + JavaScript，单文件实现，零依赖。
