# 提示词工坊 PromptWorkshop

结构化提示词优化与效果对比的网页演示工具。**《移动应用开发及安全》课程作业**，用于直观展示大模型提示词工程的价值。

输入一句大白话需求，自动生成带「角色 / 任务 / 背景 / 输出格式 / 参考示例 / 约束条件」的六要素提示词，并将**原始问法**与**优化后提示词**的回答并排对比——优化前后的差距一眼可见。

## 功能

1. **需求输入**：一句大白话描述需求，支持 5 种任务场景（通用 / 编程 / 文案 / 数据分析 / 学习辅导），场景决定生成提示词的专业身份。
2. **六要素结构化**：自动生成 角色、任务、背景、输出格式、参考示例、约束条件，逐项可编辑，底部完整提示词实时同步。
3. **效果对比**：同一需求的「原始提示词」与「优化后提示词」并排回答，左侧笼统敷衍、右侧结构化有条理。
4. **一键复制**：生成的完整提示词可直接复制到任意大模型对话框使用。

## 两种运行模式

| 模式 | 说明 |
| --- | --- |
| 演示模式（默认） | 内置规则引擎与场景回答模板，**完全离线**，无需 API Key，开箱即用 |
| 真实 API 模式 | 兼容 OpenAI Chat Completions 接口，预设 DeepSeek / 通义 / Kimi / OpenAI，可自定义 Base URL |

真实 API 模式的密钥仅保存在浏览器 `localStorage`，不写入代码、不提交仓库，答辩演示不会泄露。

## 运行

双击 `index.html` 用浏览器打开即可，**无需安装环境、无需启动服务器**。

若使用真实 API 模式：点击右上角「设置」→ 选择服务商或填自定义接口地址 → 填入 API Key 与模型名 → 保存后切到「真实 API」标签。

## 对应知识点

| 知识点 | 在项目中的体现 |
| --- | --- |
| 六要素提示词结构 | 六张可编辑卡片，逐项拼装为完整提示词 |
| 角色设定 Role Prompting | 场景选择决定「你是一位资深 XX」的身份描述 |
| 少样本示例 Few-shot | 「参考示例」要素内置输入→输出样例 |
| 输出格式约束 | 「输出格式」要素指定结构、条数、字段 |
| 评估与迭代 | 原始 vs 优化并排对比，差异即评估依据 |

## 技术栈

原生 HTML + CSS + JavaScript，零依赖、零构建，纯静态页面。使用 CSS 变量管理主题色，`fetch` 调用 OpenAI 兼容接口，`localStorage` 持久化配置。
