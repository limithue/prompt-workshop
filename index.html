这个作业用到了哪些提示词工程知识？

1. 六要素结构：角色 / 任务 / 背景 / 输出格式 / 示例 / 约束，对应课堂讲的提示词构成。

2. 角色设定：为不同场景指定专家身份，让模型进入专业语境。

3. 少样本示例（Few-shot）：在提示词里给出参考输出，引导风格与结构。

4. 输出格式约束：明确要求分点、标题、代码块等，结果更可用。

5. 对比验证：同一需求两种问法并排对比，直观证明提示词工程的价值——这正是"评估与迭代"环节。
